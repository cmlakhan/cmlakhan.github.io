# cmlakhan.github.io

Personal academic homepage built with Jekyll and the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

## Setup after cloning

Run this once to enable the pre-commit hook that auto-sorts the reading list:

```bash
git config core.hooksPath .githooks
```

## Reading List

- Edit `_data/reading_list_input.yml` to add papers. Just append entries in any order — duplicates and repeated categories are fine.
- `_data/reading_list.yml` is auto-generated by the pre-commit hook. Don't edit it manually.
- When you commit changes to the input file, the hook runs `scripts/sort_reading_list.py` automatically. It merges duplicate categories/subcategories, deduplicates papers by title, and sorts everything alphabetically.

### Entry format

```yaml
- name: "Category Name"
  subcategories:
  - name: "Subcategory Name"
    papers:
    - title: "Paper Title"
      authors: "Author A, Author B"
      venue: "Journal, Year"
      link: "https://..."
      notes: ""
```

You can repeat the same category/subcategory name across multiple blocks — they will be merged automatically.
