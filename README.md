# cmlakhan.github.io

Personal academic homepage built with Jekyll and the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme.

## Setup after cloning

Run this once to enable the pre-commit hook that auto-sorts the reading list:

```bash
git config core.hooksPath .githooks
```

## Reading List

- Edit `_data/reading_list.bib` to add papers. Just paste BibTeX entries with `category` and `subcategory` fields.
- `_data/reading_list.yml` is auto-generated by the pre-commit hook. Don't edit it manually.
- When you commit changes to the `.bib` file, the hook runs `scripts/sort_reading_list.py` automatically. It groups by category/subcategory, deduplicates papers by title, and sorts everything alphabetically.

### Entry format

```bibtex
@article{somekey,
  title = {Paper Title},
  author = {Author A and Author B},
  journal = {Journal Name},
  year = {2025},
  url = {https://...},
  category = {Category Name},
  subcategory = {Subcategory Name}
}
```

Optional fields: `code`, `notes`, `booktitle` (used instead of `journal` for conferences), `doi` (used as link if no `url`).
